# Hey, I'm Soheyl.

I build things for the web, mostly with TypeScript.

My current project is a Chrome extension that keeps notes and captured
content organized while you work in ChatGPT. It started with a simple
problem: useful context gets scattered across conversations. Now it has
projects, page capture, local storage, and backups.

→ [AI Workspace](https://github.com/Soheyl-Khajian/AI-Workspace-Ext)

I've also built a storefront from the database up: a Next.js frontend,
a NestJS API, Payload CMS, and PostgreSQL. It handles accounts, carts,
and orders; payments are simulated. Getting those pieces to work together
taught me a lot about the less glamorous side of full-stack development.

→ [Watcher Store](https://github.com/Soheyl-Khajian/Watcher-Store)
